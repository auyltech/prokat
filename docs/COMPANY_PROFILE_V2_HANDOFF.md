## Где остановились

Регистрация/модерация компании, отдельный баланс, руководитель, приглашения диспетчеров уже реализованы. В текущем проходе добавлены собственная нижняя панель, парк/карточка компании, галерея, рекламная информация/тарифы/город, статистика, видимость, парк по категориям через формы владельца, наследование города, обязательное фото и необязательные характеристики. Админка показывает отдельную сводку и парк; личные списки исключают корпоративную технику. HTTP-контекст компании проверяется по участникам, медиа закрыто для посторонних. Удаление личного аккаунта сохраняет корпоративные активы.

Расход компании/онлайн-часы, заказы/запросы/чаты, размещение в клиентском каталоге и бронирование пользователь явно отложил. Соответствующие нижние вкладки пока показывают стандартное уведомление о следующем этапе. Баланс 10 000 минут ранее начислен при одобрении; расход не подключён. Sharing использует существующий renderer и настроенный SHARE_BASE_URL; минимальная страница `/c/:id` существует только локально до будущей публикации.

Установить `adb install -r prokat/build/app/outputs/flutter-apk/app-debug.apk`, не удаляя данные аккаунта. Не забыть сначала подключить/разблокировать телефон. Предыдущая бесконечная заставка возникала при сборке без Mapbox token.
