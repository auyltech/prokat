## Готовый сценарий

Карточка частного объявления показывает фото, владельца и его доступность, характеристики (если API их возвращает), тарифы и описание. Иконка чата без текста открывает обсуждение без Booking. «Отправить запрос» сначала открывает форму адреса, тарифа, даты/времени и комментария. Back возвращает карточку, сохраняя поля.

В обсуждении клиент нажимает карточку техники и отправляет условия. Сервер создаёт Booking CREATED в том же чате; переписка сохраняется. Заказ дальше использует прежние статусы и механизм подтверждения/торга. Форма сейчас выбирает опубликованный тариф, произвольная согласованная цена в ней ещё не добавлена.

Владелец OFFLINE может получить сообщение клиента и уведомление. Для ответа на новое обсуждение или прямой запрос CREATED включает ONLINE. После CONFIRMED этот дополнительный запрет ответа снят. Компания и общие заявки не переведены в новую модель.

## Реализация

- Backend: миграция `20261013160000_direct_equipment_inquiries` уже применена к local; `Chat.inquiryEquipmentId`, endpoint открытия обсуждения, привязка `inquiryChatId` при создании заказа. User row lock защищает лимит20 обсуждений от параллельного открытия. Форма без явного chatId тоже переиспользует открытое обсуждение этой техники. Техника с историей обсуждений архивируется вместо удаления с FK-ошибкой.
- `inquiryEquipment` возвращает `EquipmentPublicDTO` с тарифами/обложкой, без телефона/госномера/GPS/служебных полей. Detail чата явно возвращает type/status.
- Mobile: общая `EquipmentListingContent` для каталога и публичной ссылки; `ProkatFlowScope` включает новые цвета/обводки существующих контролов только на этих экранах. Старый UI других разделов не заменён. Форма вынесена над shell, переход в чат использует go. OTP/durable intent публичной ссылки сохранены.
- При появлении первого Booking в ранее пустом обсуждении `CurrentChatNotifier` догружает полный detail: короткая socket delta содержит только статус/цену, иначе карточка показывала неизвестную технику/дату. Последующие изменения статуса не добавляют запросов.
