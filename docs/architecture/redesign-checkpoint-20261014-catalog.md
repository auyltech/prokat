# Редизайн каталога — 14 октября 2026

Чат и запрос согласованы пользователем. Следующий срез — клиентский каталог, выбор категории и поиск. Ветка `feat/redesign-20261013`, локальная. Backend/web этого среза не меняются; push/merge/deploy не выполнять, stash оборудования не применять.

## Что изменено

- MainScaffold включает обновлённые цвета только на searchList. Scope/Theme/Scaffold остаются в одной структуре при смене маршрута: enabled переключается, навигационная оболочка не заменяется условно другим типом родителя.
- По уточнению пользователя: поиск виден сразу, справа синяя sliders кнопка полного выбора категорий, ниже горизонтальные овальные quick chips. Используются реальные первые6 категорий в порядке каталога, без выдуманной статистики популярности. Выбранная категория вынесена первой, All reset рядом; после выбора горизонтальный контроллер возвращается в0, вертикальный список не прокручивается. Прежние controller,500ms debounce, BrowseGroupSession, all-option и сброс поиска только текущей группы сохранены. Picker — компактные4:3 rows с blue selection/check; неработающие spec filters не добавлялись.
- Существующие UIkit AppTabs/ProkatAppBar/AppNavigationBar учитывают scope: белые поверхности, navy/blue цвета, более спокойные размеры текста, активная pill вместо свечения. Вне scope прежнее оформление. Город — компактная pill с прежним CityPickerSheet/clientcity callback и локализованным названием.
- Карточка: на фото реальные owner-online/city и цена с «от» при isStartingFrom; отдельная зона для share/favorite, название, владелец и рейтинг/нет отзывов, три приоритетные видимые характеристики. Hero учитывает высоту длинных подписей при крупном тексте. После первого S22 preview карточки уплотнены: no-spec company fixture имеет высоту менее380px в widget test. «Подробнее» открывает тот же callback карточки техники/компании; новый заказ от этой кнопки не создаётся. Share/favorite/companyId и UGC report/block сохранены; unknown spec icons не выдаются за rating stars. Цвета и CTA используют существующие flow presets.
- Пустой поиск: отдельные RU/KK/EN строки «Объявления не найдены» с подсказкой изменить запрос/категорию/город, белая поверхность и новая палитра. EquipmentEmptyTile defaults вне scope прежние.

Сортировка списка, HTTP query/category/city, ETag/cache, pagination, API и серверные статусы не менялись. Миграций, seed, новых библиотек и аналитических событий нет. Дизайн гостевого каталога/парка/заявок вне этого среза.
