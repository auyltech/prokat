При крупном тексте значимые данные переносятся, жёсткой высоты карточки нет.
- Закрытие обсуждения: heading/tooltip остаётся подробным, CTA RU «Завершить» / KK «Аяқтау» / EN «Finish». Общий alert выравнивает высоту кнопок; outlined в Flow адаптируется к крупному тексту и использует общий радиус16.

## Уведомления

- `ForegroundNotificationPresenter` — единый баннер поверх root overlay для socket и FCM, включая local без Firebase. Сам закрывается через6с, есть dismiss и тап с существующим безопасным route resolver. Локализуется по текущему языку, дедупликация ID10мин; прочитанные/чужой scope не показываются. Скрывается при background/logout/смене роли или company scope.
- PushNotificationService использует тот же presenter в foreground, поэтому OS local banner не дублирует внутренний. В фоне сохранён канал `prokat_alerts` max/high и звук. Изменять пользовательские Android настройки/создавать обходные каналы нельзя. Фоновую доставку через FCM на S22 здесь не проверяли: Firebase и push намеренно выключены в local replica; deviceTokens=0.
- На сервере исправлен реальный баг отзыва встречного предложения: уведомляется собеседник, а не всегда clientId. В события чата/условий добавлена явная audience. При ответе на обычное предложение имя берётся у ответившего, а не у автора предложения.
- Audience обычного сообщения берётся из роли реального ChatParticipant, с fallback по clientId/ownerId. Не считать любого получателя OWNER: это ломает поддержку с nullable clientId и company участников. После этой последней правки `tsc --noEmit` также exit0.
- Полные условия заказа теперь имеют отдельные точные RU/KK/EN push/inbox тексты (цена, адрес, время; принятие/отклонение/отзыв). Цена-only templates остаются прежними. `sendNotification` выбирает язык также для переданного data.i18n без templateKey.
- Завершение inquiry отправляет собеседнику локализованное уведомление с chatId через существующий тип CHAT_MESSAGE_CREATED. Учитываются mute/archive; повторное закрытие не создаёт новое событие. Открытие пустого чата само по себе не выдаётся за заказ; обычное первое сообщение использует существующее уведомление чата.
- Статусы Booking CREATED/CONFIRMED/CANCELLED/REJECTED/COMPLETED, предложения/ход работ уже имели producer; сохранены. Прочитаны реальные тексты шаблонов локального снимка, не менялась база шаблонов прода.
