# Locations

- Geocoding goes through `GET /locations/search` and `GET /locations/reverse` (auth). The app does not call Mapbox. Backend uses Geocoding v5, `language=ru,kk,en` in one request, `types` `address,place` (search) / `address` (reverse). Stay on v5.
- Pin flow: reverse after camera idle (~600ms), not while dragging. Coords are the overlay pin **tip**, via `pinTarget()`. House number prefers map tiles (`housenum-label` / source fallback); if miss, keep reverse `houseNumber`; the pin UI can edit it. Street options come from nearby map tiles; the reverse street is preselected when it matches. Persist tile `name_en` / `name` (kk) with the Russian canonical street — empty slots stay empty, they are not filled with the UI language. City/country still from `/locations/reverse`. Saved address uses the selected street names and the house field (same as UI). On leave, cancel the debounce and ignore in-flight reverse (`deactivate`); do not `ref.read` / `setState` after that. `autocomplete=true` stays on the search API for later; do not wire `searchLocations` or `AddressSearchSuggestions`.
- Persist `houseNumber` (scalar) and `streetNames` / `cityNames` / `countryNames` (`LocalizedNames`). Canonical `street` / `city` / `country` are typically ru. `comment` is building/entrance, not the house number.
- Display: pick names locally (`locale → ru → en`). Do not refetch on locale change. City: catalog label if the city is in `ServiceCity`, otherwise names from the location.
- Active address: `PATCH /user/profile/address`. 2xx is success even if `data` is null; do not `fromJson(null)`. The picker sheet fires this on tap and does not wait. Trailing trash on a row deletes (confirm first). `DELETE /locations/:id` unlinks the profile if that address was primary.
- There is no separate My Addresses screen. The picker sheet lists saved addresses; map pin creates new ones.
- Proximity: camera coords, or Atyrau from `MapConstants`.
