# Map

- `MapController` lives in `mapControllerProvider`. Capture it while `ref` is valid (`didChangeDependencies` / `build`). In `dispose`, call `detach` on that instance — never `ref.read`.
- After `deactivate`, ignore Mapbox camera/tap/style callbacks. Pin screens own reverse-geocode debounce and must stop it on leave.
- Pin pickers: overlay pin tip is padded onto the camera center. Coords via `pinTarget()`. House number: painted `housenum-label` under the tip, else nearest `housenum_label` in source within ~60 m, else reverse; the field is editable. Street dropdown: named `road` / `road-label` tiles within ~80 m, preselected from `/locations/reverse` when that street is in the list. Store real tile/reverse `name_ru` / `name_en` / `name` (kk); do not copy the app language into empty slots. Display picks locale locally. City/country still from reverse. Keyboard lifts only the address panel (`viewInsets`); pin Scaffolds use `resizeToAvoidBottomInset: false` so the map texture and camera stay put. Ignore camera-idle reverse while the house field is focused or the keyboard is visible.
- Map label language follows the **app** locale, not the phone language. Wait for `localeProvider.hydrated`, then `setLanguage` before `MapWidget`. On style load rewrite Streets `name_*` (`localizeLabels` alone skips layers; `kk` has no Streets field, use local `name`). Do not `watch` locale in `build` — listen and re-localize.
- Initial camera: `MapWidget.viewport` with a **stable** `CameraViewportState` instance, not a new one in `build`. Mapbox reapplies viewport when the object identity changes and snaps the camera. After init, switch to `IdleViewportState` so the user can pan. Not `cameraOptions`.
- Map taps: `MapboxMap.addInteraction(TapInteraction.onMap(...))` in `onMapCreated`, not `MapWidget.onTapListener`.
